## Modelo de servicios

Presentar una oferta única de diseño y desarrollo de sitios web con tres aplicaciones frecuentes:

- **sitios institucionales:** presencia clara para presentar actividad, servicios, información y contacto;
- **landing pages:** una propuesta concreta con jerarquía, claridad, velocidad y una acción principal;
- **rediseño / modernización:** evaluación inicial para decidir si conviene intervenir la base existente o reconstruirla.

Cada tipo necesita una explicación breve de necesidad y resultado esperado, no una lista propia de entregables. Responsive forma parte de una web bien resuelta. Formularios, SEO técnico, performance y publicación pueden agruparse como capacidades integradas según proyecto. Perfil de Empresa de Google para presencia local y preparación técnica para buscadores/asistentes de IA se comunican en un único pasaje breve de capacidades condicionadas al alcance, después de los tres tipos; no se agregan como cuarta y quinta oferta ni se prometen resultados de visibilidad.

La implementación de un diseño externo se menciona como capacidad complementaria, con atribución correcta y sin competir con la oferta principal.
